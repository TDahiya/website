Kaia — production AI assistant

Live

Text chat, browser voice and real inbound and outbound phone calls, on a Hetzner VPS behind Caddy. Sixteen tools across Google Calendar, Gmail and a Sheets CRM, Postgres with row-level security on every table, and per-provider cost tracking. About 10,000 lines across FastAPI and Next.js 15.

Spreadsheets do not touch the retrieval path. Ask for a total over €5,000 and a vector search returns rows that look like the answer, so the model invents a confident number. Instead it inspects the real schema, writes pandas, and the code runs in an isolated subprocess as an unprivileged user under CPU, memory, file-descriptor and process limits. The number is computed, not recalled.

Voice reached 0.20s first-audio once each sentence stopped being its own HTTPS request: one socket stays open and LLM tokens stream straight into it. Turn-taking broke until it keyed off speech_final rather than is_final. Two hours of confusion, one word of difference.

Hybrid RAG over EU & Irish law

Shipped

Legal questions arrive in two incompatible shapes. "AI Act Article 6(2)" and "Stamp 1G" need exact tokens, because embeddings blur an article number into its neighbours. "Can my spouse work on a Critical Skills permit" shares no vocabulary at all with the statute that answers it.

So both run, and Reciprocal Rank Fusion merges them using ranks rather than scores, which means two incompatible scales never have to be normalised against each other. Recall@10 goes to 93.3% against 91.7% for BM25 alone and 86.7% for dense alone. Multi-hop recall goes 80% to 100%. BM25 comes from SQLite FTS5, so lexical search costs zero dependencies and zero RAM.

The evaluation layer deleted one of this project's own features. A retry gate fired whenever grounding fell below 0.45. Across 36 answers grounding never left 0.68 to 0.96, so it never fired once, and the lower-grounding half scored 98.2% faithfulness against 91.7% for the upper half. The signal was inversely related to the thing it gated. No threshold fixes that, so the retry is gone and nothing replaced it.

Prompt Firewall

Shipped

A two-layer filter between users and an LLM. A sub-millisecond regex pass catches known injection signatures, base64 blobs and Unicode homoglyphs, and blocks on certainty alone. Anything it is unsure about falls through to a classifier returning a structured verdict, category and confidence.

The point is the ordering: the cheap layer absorbs the common case so the expensive one only ever sees genuine ambiguity. Shipped with a test suite and CI.

LLM safety is not one property. It is two.

Research · MSc practicum, DCU

Safety benchmarks test one phrasing at a time. If a model refuses one wording and complies with a semantically identical rewrite, nothing catches it. I wrote 329 adversarial seed prompts grounded in 14 MITRE ATT&CK techniques and expanded them to 1,645 variants through four controlled paraphrasing strategies, so every variant means the same thing and only the wording moves.

Five autonomous agents then queried a different production LLM each — Claude, GPT-4o, DeepSeek, Mistral, Qwen — with independent rate limiting, structured JSON parsing and fault-tolerant recovery. 8,225 requests ran in parallel with no human intervention, and a three-judge G-EVAL consensus produced 24,675 verdicts by majority vote.

The result I did not expect: strict inconsistency ran at 60.2%, and the safest models were the least consistent. The model with the best safety score (MSA 59%) had the worst inconsistency rate (IIR 72.6%). Alignment and behavioural consistency are independent properties, so a single safety number tells you less than it appears to.
