Prompt Firewall

Real-time prompt injection detection that sits between your users and your LLM. Every input is classified in milliseconds: safe ones pass straight through, injections are blocked before they reach the model.

Live demo Source

Two layers, and the ordering is the point

The first layer is a sub-millisecond regex pass. It catches known injection signatures ("ignore previous instructions", "you are now [role]"), base64 blobs and Unicode homoglyphs, and it blocks on certainty alone.

Anything it is unsure about falls through to an LLM classifier with structured output, returning a verdict, a category and a confidence score. Above the confidence threshold the request is blocked; below it, it passes.

The cheap layer absorbs the common case so the expensive one is never spent on traffic that was obviously fine. Put the classifier first and you pay roughly 300ms and an API call on every single request, including the overwhelming majority a regex would have cleared instantly.

What is in the repo

FastAPI, a Postgres schema for logging verdicts, a small frontend for trying it by hand, a Dockerfile, and a test suite covering both the pattern layer and the API surface, wired to CI.
